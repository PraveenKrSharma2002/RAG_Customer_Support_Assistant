# RAG Customer Support Assistant

RAG-Based Customer Support Assistant is an AI-powered system built using Python, Streamlit, and LangGraph. It retrieves information from uploaded company policy PDFs and provides contextual answers using Retrieval-Augmented Generation (RAG) with HITL escalation support for unsupported queries.

## Features

- Dynamic PDF Upload
- Document Chunking
- Retrieval-Based Question Answering
- HITL Escalation
- Streamlit UI
- LangGraph Workflow

## Tech Stack

- Python
- Streamlit
- LangChain
- LangGraph
- PyPDFLoader
- ChromaDB
